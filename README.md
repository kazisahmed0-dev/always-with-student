# Always With Student

An Android app for students to calculate results, manage notes, set reminders, and store memories.

## Features
- Result calculation (GPA/marks)
- Note management
- Reminder system for tasks/exams
- Memories section for saving important student moments

## Installation
- Clone the repository
- Open in Android Studio
- Run the app

## Usage
Students can add notes, calculate results, set reminders, and save memories easily.
